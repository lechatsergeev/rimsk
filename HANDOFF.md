## Как теперь публикуется

Переехали со старого механизма (положить сборку в ветку `gh-pages` и
ждать встроенный сборщик с Jekyll) на **GitHub Actions**:
`.github/workflows/deploy.yml` — собирает и выкладывает при пуше в `main`.

Источник публикации в настройках репозитория переключён на
`GitHub Actions`. Ветка `gh-pages` больше не нужна.

Скрипты `npm run deploy` и `predeploy` **удалены намеренно** — запускать
их теперь некуда.

Телефон +7 (958) 178-10-78, почта eep.sergeev.alexey@gmail.com.

**Презентация приготовления на первом экране.** Шесть шагов с
прилипанием прокрутки: первый экран → Тесто → Формовка → Печь →
Заморозка → Готово. Четыре стадийные модели плюс готовая пицца стоят
шеренгой в одной сцене WebGL, активная впереди, остальные в тени.
У каждого шага свой фон.

**Модели пережаты:** 21 МБ → 1.8 МБ. Текстуры 4096 → 1024, геометрия
meshopt с прореживанием. Оригиналы `images/*-ktx.glb` не тронуты и не
в git. В сборку идут `images/*-opt.glb`.

Цепочка, если понадобится повторить:
```
npx @gltf-transform/cli ktxdecompress in.glb a.glb
npx @gltf-transform/cli resize a.glb b.glb --width 1024 --height 1024
npx @gltf-transform/cli etc1s b.glb c.glb
npx @gltf-transform/cli optimize c.glb out.glb --compress meshopt \
  --simplify true --simplify-error 0.0005 --texture-compress false
```

## Что осталось незакрытым

**Название.** «Мацца» не финальное, хотелось провокационное. Живёт
одной константой в `src/content/brand.ts` — замена в один правок.

**Три тяжёлые модели** не оптимизированы: `pizza.glb` 4.95 МБ,
`margarita.glb` и `gorgonzola.glb` по 1.5 МБ. Пережать той же цепочкой —
публикация похудеет с 14 МБ примерно до 5.

**Мусор в репозитории.** В корне лежат неотслеживаемые скриншоты
(`IMG_*.PNG`, «Снимок экрана…»), `Архив.zip`, папка «Прием заявок» с
двумя серверами и своими node_modules. Каталог `.planning/` описывает
отменённую развилку horeca/retail. Около полусотни неиспользуемых
компонентов в `src/app/components/ui/`.

## Грабли, на которые уже наступали

**Локальный просмотр только по пути `/rimsk/`** — проект собран с этим
базовым путём. По голому корню будет редирект или пустота.
```
npm run build && npx vite preview --port 4177
http://localhost:4177/rimsk/
```

**Не класть `.git` внутрь `dist/`.** Такой каталог там уже жил и при
публикации затирал адрес удалённого репозитория. Удалён.

**Гидрация.** Всё, что рендерится только на клиенте, обязано совпадать
с сервером в первом рендере — иначе React отбрасывает пререндер целиком
и рисует страницу заново. Для этого есть `src/lib/use-mounted.ts`.
Раскладку на JS-брейкпоинтах строить нельзя, только CSS: уже был случай,
когда на телефоне залипал десктопный макет.

**Отступы.** В блоках соблюдается правило внутреннего и внешнего:
расстояние внутри группы заметно меньше, чем между группами.
Разделительные линии не нужны, если расстояния расставлены верно.
