# Мацца B2B Segmented Landing

## What This Is

Маркетинговый B2B-лендинг для бренда Мацца, который продаёт римскую пиццу бизнес-клиентам. Сейчас продукт смещается с одного сценария для хорека к двум отдельным сегментам: хорека и ретейл, с отдельной точкой входа и независимыми страницами под каждый сегмент.

## Core Value

Пользователь должен быстро попасть в свой сценарий бизнеса и увидеть релевантное предложение без путаницы между хорекой и ретейлом.

## Requirements

### Validated

- ✓ Сайт уже существует как React/Vite-лендинг с контентом для хорека

### Active

- [ ] Добавить первый экран с выбором сегмента `horeca` или `retail`
- [ ] Развести контент на две отдельные страницы с независимой дальнейшей правкой
- [ ] Сохранить существующий хорека-лендинг рабочим после сегментации
- [ ] Подготовить retail-страницу как отдельную копию horeca-версии для последующей адаптации

### Out of Scope

- Полная контентная переработка retail-страницы — отдельная следующая фаза
- Изменение бизнес-модели, CRM или бэкенда — в проекте сейчас только фронтенд-лендинг
- Полный редизайн всех внутренних секций — не нужен, пока не зафиксирован новый сегментный вход

## Context

Проект уже содержит существующий код лендинга на React + Vite без текущей GSD-инициализации. Пользовательский запрос на 2026-04-01: добавить на первом экране развилку "вы из хорека или из ретейла?", после выбора вести на нужную страницу, а текущую horeca-страницу продублировать под retail для дальнейшего редактирования.

## Constraints

- **Tech stack**: React + Vite + TypeScript — нужно сохранять совместимость с существующим фронтенд-стеком
- **Brownfield**: Код уже существует — нельзя ломать текущую horeca-страницу и established visual language
- **Product scope**: Сначала архитектурное разведение сегментов, потом контентная адаптация — чтобы не смешивать структурную и контентную работу
- **Verification**: Изменения должны проходить `npm run build` и быть доступны локально через dev-сервер

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Вход в лендинг начинается с выбора сегмента | Нужно разделить аудитории до погружения в контент | ✓ Good |
| Horeca и retail ведутся на разные страницы внутри одного фронтенда | Это позволяет адаптировать тексты и структуру независимо | ✓ Good |
| Retail на старте создаётся как копия horeca | Это быстрее, чем проектировать retail с нуля до проверки структуры | ✓ Good |
